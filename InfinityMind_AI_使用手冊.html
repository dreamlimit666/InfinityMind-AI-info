系統簡介

InfinityMind AI 是一個企業級的 AI 知識問答系統，支援：
- 🤖 多機器人實例（5 個獨立 Bot）
- 💬 多渠道整合（LINE / Teams / WebChat）
- 📚 RAG 知識檢索
- 🔐 完整權限管理（用戶/角色/資料夾/文檔分級）
- 🖼️ 圖片辨識功能（Azure Vision API）
- 🌓 深色/淺色主題切換- 🌐 內外部共用：同時支援內部員工與外部訪客，灵活切換驗證模式

登入系統

預設登入頁面

登入方式

本地帳號登入
- 輸入 Email 和密碼
- 系統唯一登入方式
- 需由管理員建立帳號

自訂登入頁面

特色：
- ✅ 支援企業 Logo 自訂
- ✅ 背景圖片可配置
- ✅ 登入提示文字可修改

用戶管理

3.1 新增使用者 - 帳號管理

必填欄位：
- 📧 Email：系統唯一識別碼
- 👤 姓名：使用者顯示名稱
- 🔑 密碼：本地帳號登入密碼

選填欄位：
- 📱 LINE ID 綁定：綁定 LINE 渠道
- 💼 部門：組織架構管理
- 📊 帳號狀態：啟用/停用

3.2 新增使用者 - 權限設置

權限配置項目：

📁 資料夾權限

  • 多選資料夾列表
  • 決定使用者可存取哪些知識庫
  • 支援細粒度控制

🤖 Bot 訪問權限

  • 勾選可使用的 Bot 實例
  • 支援 Bot 1 ~ Bot 5 獨立授權

🛡️ 角色指派

  • 管理員（Admin）
  • 一般用戶（User）
  • 訪客（Guest）

權限繼承規則：

管理員 > 一般用戶 > 訪客
   ↓         ↓        ↓
 全部權限  指定權限  唯讀

3.3 新增使用者 - 安全許可

安全分級制度（4 級）：

級別 名稱 標籤 說明
Level 1 公開 🌐 Public 無限制文檔
Level 2 內部 🏢 Internal 企業內部文檔
Level 3 機密 🔒 Confidential 敏感業務資料
Level 4 極機密 🔐 Secret 最高機密文檔

設定項目：
- 📋 安全許可級別：選擇 1-4
- 📅 授權日期：許可生效時間
- ⏰ 過期日期：許可失效時間（可選）
- 👤 授權人員：記錄核准者
- 📝 授權原因：稽核用途

存取規則：

使用者許可級別 ≥ 文檔分級 → 可存取
使用者許可級別 < 文檔分級 → 拒絕存取

3.4 編輯使用者

可修改項目：
- 🔐 安全許可級別
- 📁 資料夾權限
- 🤖 Bot 訪問權限
- 🔒 帳號狀態（啟用/停用）
- 💬 渠道密碼狀態：顯示是否已設定 LINE/WebChat 對話密碼

安全提示：

⚠️ 修改權限後立即生效，使用者下次查詢時會套用新權限。

機器人設定

4.1 多組 Bot 配置

支援多 Bot 實例：
- 🤖 Bot 1 ~ Bot 5：5 個獨立機器人
- 🎯 獨立配置：各自擁有專屬設定
- 🔑 獨立認證：每個 Bot 有獨立的 Azure Bot Service 憑證

適用場景：
- 📊 部門隔離：不同部門使用不同 Bot
- 🌍 多語言支援：中文 Bot / 英文 Bot
- 🎭 角色專業化：HR Bot / IT Bot / Sales Bot

4.2 資料夾掛載與驗證需求

配置項目：

📁 掛載資料夾

  • 多選資料夾列表
  • 決定此 Bot 可檢索哪些知識庫
  • 支援動態調整

範例配置：

Bot 1 (HR)    → 掛載：人事資料夾、公告資料夾
Bot 2 (IT)    → 掛載：技術文檔、操作手冊
Bot 3 (Sales) → 掛載：產品資訊、銷售資料

🔐 使用者驗證需求

  • 啟用驗證：要求使用者登入後才能對話
  • 停用驗證：允許訪客模式（匿名對話）

決策建議：

內部敏感資料 Bot → 啟用驗證 ✅
公開客服 Bot     → 停用驗證 ❌

文檔與資料夾管理

5.1 資料夾管理 - 啟用狀態與公開性

資料夾屬性配置：

🔄 啟用/停用

  • 啟用：Bot 可檢索此資料夾的文檔
  • 停用：暫時隱藏，不影響文檔本身

🌐 公開/內部

  • 公開（Public）：適用於 FAQ、使用說明等
  • 內部（Internal）：限內部員工存取

🎨 資料夾屬性

  • 📝 名稱：資料夾顯示名稱
  • 🏷️ 描述：用途說明
  • 📊 預設分級：新增文檔的預設安全級別
  • 📁 文檔數量：即時統計

5.2 資料夾內文件管理

文件列表功能：
- 📄 檔案名稱：上傳的原始檔名
- 📅 上傳日期：建立時間
- 👤 上傳者：記錄操作人員
- 📏 檔案大小：空間使用統計
- ⚙️ 操作：編輯、刪除、下載

支援檔案格式：

文件：.pdf, .docx, .txt, .md
試算表：.xlsx, .csv
簡報：.pptx

5.3 文件分級管理

單一文件安全分級：

每個文檔可設定獨立的安全級別：
- 🌐 Level 1 - Public：公開文檔
- 🏢 Level 2 - Internal：內部文檔
- 🔒 Level 3 - Confidential：機密文檔
- 🔐 Level 4 - Secret：極機密文檔

分級變更記錄：
- 📝 變更時間：自動記錄
- 👤 操作人員：稽核追蹤
- 💬 變更原因：必填說明

分級影響：

使用者查詢時，系統會：
1. 檢查使用者安全許可級別
2. 過濾出可存取的文檔
3. 僅檢索符合權限的內容

訪客管理

6.1 訪客列表

訪客模式功能：

當 Bot 設定為「停用使用者驗證」時，系統會：
- 🎭 自動建立訪客帳號：格式 guest_<channel>_<user_id>
- 📊 追蹤對話紀錄：完整保留對話歷史
- 🔍 管理介面查看：管理員可監控訪客使用狀況

內外部共用特色：
- 🏢 內部使用：開啟驗證 → 員工登入後使用，享有完整權限控制
- 🌐 外部客服：停用驗證 → 訪客免登入使用，Bot 成為 24/7 智能客服
- 📈 大數據分析：訪客對話可用於：
- 熟門問題分析
- 用戶行為模式挖掘
- FAQ 優化依據
- 知識庫缺口發現

訪客資訊顯示：
- 🆔 訪客 ID：系統自動生成
- 💬 渠道：LINE / Teams / WebChat
- ⏰ 首次對話時間
- 📈 對話次數：統計總互動數
- 🕐 最後對話時間

6.2 訪客對話紀錄

對話歷史查詢：

點擊訪客後可查看：
- 💬 完整對話內容：問題與回答
- 🕒 時間戳記：精確到秒
- 🤖 使用的 Bot：Bot 1 ~ 5
- 📚 引用文檔：RAG 檢索的參考資料
- 🎯 Prompt 名稱：使用的系統提示詞

分析功能：
- 📊 熱門問題統計
- 🎭 訪客行為分析
- 💡 改進建議：發現知識庫缺口- 📈 大數據應用：
- 訪客對話數據可匯出分析
- 識別用戶需求趨勢
- 優化客服回答策略
- 提升 Bot 準確率

6.3 數據分析功能

數據分析主頁面

系統提供完整的訪客數據視覺化分析，幫助您深入了解訪客行為、發現知識庫缺口、優化FAQ內容。

核心功能：

1. 訪客趨勢分析
- 📈 每日訪客數趨勢圖
- 📊 對話數量變化追蹤
- 🔄 自動計算與前期對比增長率
- 📅 支援 7 天、30 天、90 天時間範圍

2. 熱門問題排行榜
- 🔥 Top 10 最常被問的問題
- 📊 顯示問題出現次數
- 🌐 標示問題來源渠道（WebChat、LINE、Teams）
- 💡 幫助快速識別高頻需求

3. 知識庫缺口分析
- 🔍 自動識別無參考資料的高頻問題
- ⚠️ 標示需要補充文檔的問題
- 📈 顯示問題出現次數排序
- ✅ 提供「新增文檔」快速操作建議

4. 數據匯出功能
- 📥 一鍵匯出 CSV 格式報表
- 📊 包含核心指標、熱門問題、渠道分佈、知識庫缺口等完整數據
- ✅ 完美支援 Excel 開啟（UTF-8 編碼，無亂碼）
- 📅 自動標記報表生成時間

對話功能

7.1 WebChat - 使用者登入驗證

WebChat 認證流程：

步驟 1： 輸入 Email

使用者: john@company.com
Bot: ✅ Email 確認，請輸入您的對話密碼：

步驟 2： 輸入密碼

使用者: [輸入密碼]
Bot: ✅ 驗證成功！歡迎，John
     您現在可以開始對話了 😊

首次使用：

Bot: 🔐 請設定您的對話密碼：
     💡 密碼將用於後續登入，請妥善保管。

7.2 WebChat - 圖片辨識

圖片上傳功能：

  1. 📎 點擊附件按鈕
  2. 🖼️ 選擇圖片（支援 JPG, PNG, GIF, WEBP）
  3. 🤖 AI 自動分析：
    - OCR 文字識別（gpt-4o 多模態能力）
    - 物體識別
    - 場景理解
    - 顏色分析

分析範例：

使用者: [上傳書籍封面]
Bot: 這本書的書名是《從心解脫：數位時代的心靈降躁法》
     由格龍仁波切所著，商周出版。
     封面設計採用寧靜的湖泊與山景...

7.3 WebChat - 圖片辨識 + 後續對話

對話連續性：

系統會保留圖片辨識結果作為對話上下文：

輪次 1：
使用者: [上傳圖片]
Bot: [圖片識別] 這是一本關於冥想的書籍...

輪次 2：
使用者: 這本書適合初學者嗎？
Bot: 根據剛才的圖片，這本《從心解脫》確實適合初學者。
     它提供了簡單的入門練習...

智能整合：
- 🧠 圖片+RAG：結合圖片識別與知識庫檢索
- 🔍 自動驗證：RAG 檢索驗證圖片識別準確性
- 💬 上下文記憶：保留 3 輪對話（3 分鐘內）

7.4 LINE - 知識問答 + 圖片辨識

LINE 渠道整合：

文字問答：

使用者: 公司的請假流程是什麼？
Bot: 根據人事規章，請假流程如下：
     1. 登入人事系統
     2. 填寫請假單...

     主要功能包括：心率監測、睡眠追蹤...

LINE 特色功能：
- 📱 推播通知：即時回應
- 🔗 Rich Menu：快速功能選單
- 🎨 Flex Message：豐富訊息卡片

使用者: 我叫 Nick

輪次 2：
使用者: 我的名字是？
Bot: 你叫 Nick

輪次 3：
使用者: [上傳文件照片]

輪次 4：

Azure 資源管理

9.1 Azure 資源清單

InfinityMind AI 使用的 Azure 服務：

🤖 Azure Bot Service

  • Bot 1 ~ 5：5 個獨立 Bot 註冊
  • 渠道整合：LINE, Teams, WebChat, DirectLine

🗄️ Azure App Service

  • chatbot-bot-api：FastAPI 後端服務
  • chatbot-ui：Vue.js 3 前端 + Flask API
  • chatbot-scheduler：排程任務服務
  • 運行環境：Python 3.12, Node.js 20

🧠 Azure OpenAI Service

  • gpt-4o：主要 LLM 模型（多模態，支援文字與圖片）
  • text-embedding-3-small：向量嵌入模型

💾 MongoDB Atlas（第三方）

  • AI_DB 資料庫：主資料庫
  • Vector Search：1536 維向量索引
  • Collections：users, documents, chatlog, bots...

📦 Azure Blob Storage

  • documents：文檔儲存
  • image：圖片儲存
  • private-files：私密檔案

🔍 Azure Application Insights

  • 效能監控：API 回應時間
  • 錯誤追蹤：即時錯誤通知
  • 使用分析：用戶行為統計

註：實際使用費用依據系統流量及用量而定，建議根據實際需求自行評估。

B. 常見問題（FAQ）

聯繫管理員重設密碼。

確認檔案大小 < 10MB，格式為 JPG/PNG。
